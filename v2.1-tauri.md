**Version:** 2.1-Tauri  
**Datum:** 2025-01-20  
**Status:** Implementierungsspezifikation  
**Basis:** v2.1 (ratatui) → Tauri GUI Adaption  
**Design System:** Catppuccin Mocha inspired

## 1. Einführung & Zielsetzung

### 1.1 Überblick

Der Schließfach-Manager v2.1-Tauri ist eine moderne Desktop-Anwendung zur Verwaltung von Schließfächern, Verleihvorgängen, Finanzen und Standorten. Diese Version adaptiert die bewährte v2.1-Logik in eine grafische Benutzeroberfläche mit folgenden Zielen:

- **Moderne GUI-Erfahrung:** Intuitive Maus- und Tastatur-Navigation, visuelles Feedback
- **Feature-Parität mit TUI:** Alle Features der v2.1-ratatui-Version bleiben erhalten
- **Cross-Platform Desktop:** Native Performance durch Tauri (Rust + WebView)
- **Responsive Design:** Anpassung an verschiedene Fenstergrößen (min. 900×600, optimal 1280×800)
- **Sidebar-Navigation:** Kategorien (Fenster) mit verschachtelten Seiten (Tabs)
- **Wizard-Dialoge:** Multi-Step-Formulare für komplexe Workflows
- **Dashboard mit Charts:** Visuelle Darstellung von Belegungstrends und Statistiken
- **Konfigurierbare Preise:** Pfand, Jahresgebühren über Einstellungs-UI
- **Export/Import mit UI:** Datei-Dialoge für TOML, JSON, CSV, Markdown
- **Audit-Logging:** Vollständige Nachverfolgbarkeit in Tabellen-UI
- **Toast-Benachrichtigungen:** Ersatz für TUI-Statusbar-Messages
- **Screensaver-Funktion:** Automatische Aktivierung nach Inaktivität (optional, GUI-adaptiert)
- **Keyboard Shortcuts:** Vollständige Tastatur-Navigation parallel zur Maus

### 1.2 Design-Philosophie

**Von TUI zu GUI – Was bleibt gleich:**
- Gesamte Business-Logik und Datenstruktur
- Navigation-Hierarchie (Kategorien/Windows → Seiten/Tabs)
- Workflow-Schritte (Wizards)
- Datenbank-Schema und Migrationen
- Export/Import-Formate

**Was sich ändert:**
- Terminal → WebView-basierte UI mit HTML/CSS/React
- Keybind Bar → Tooltips + Shortcuts-Overlay (Strg+?)
- Status Bar Messages → Toast-Benachrichtigungen
- ASCII-Animationen → CSS/SVG-Animationen
- Fixed Character-Layout → Responsive Pixel-Layout

### 1.3 Abwärtskompatibilität

- **Datenbank:** Identisches Schema wie v2.1, volle Kompatibilität
- **Migration:** Bestehende v2.1-Datenbanken werden automatisch erkannt und können weiterverwendet werden
- **Export/Import:** Alle Formate (TOML, JSON, CSV) bleiben kompatibel

### 1.4 Zielplattformen

- **Betriebssysteme:** Windows 10/11, macOS 11+, Linux (Debian/Ubuntu, Fedora, Arch)
- **Mindestauflösung:** 900×600 Pixel
- **Optimale Auflösung:** 1280×800 Pixel oder höher
- **Browser Engine:** System WebView (WebView2 auf Windows, WebKit auf macOS/Linux)

## 3. Datenbank-Schema

### 3.1 Identisch zu v2.1

Das Datenbank-Schema ist **vollständig identisch** zur v2.1-ratatui-Version:

#### Bestehende Tabellen
- `lockers` (id, number, location, size, is_damaged, notes, created_at)
- `rentals` (id, locker_id, renter_name, renter_email, renter_phone, start_date, end_date, deposit_paid, deposit_returned, notes, created_at)
- `payments` (id, rental_id, amount_cents, payment_date, payment_type, notes, created_at)
- `locations` (id, name, created_at)

#### Neue Tabellen (v2.1)

##### settings

##### audit_log

```sql
CREATE TABLE IF NOT EXISTS audit_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp TEXT NOT NULL DEFAULT (datetime('now')),
    action TEXT NOT NULL,
    entity_type TEXT NOT NULL,
    entity_id INTEGER,
    details TEXT,
    username TEXT DEFAULT 'system'
);

CREATE INDEX IF NOT EXISTS idx_audit_timestamp ON audit_log(timestamp);
CREATE INDEX IF NOT EXISTS idx_audit_entity ON audit_log(entity_type, entity_id);
```

##### occupancy_history

```sql
CREATE TABLE IF NOT EXISTS occupancy_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    snapshot_date TEXT NOT NULL,
    total_lockers INTEGER NOT NULL,
    occupied_lockers INTEGER NOT NULL,
    occupancy_percent REAL NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_occupancy_date ON occupancy_history(snapshot_date DESC);
```

### 3.2 Migration-Strategie

```rust
// src/db/migrations.rs

pub fn run_migrations(conn: &Connection) -> Result<()> {
    let version = get_db_version(conn)?;
    
    if version < 1 {
        create_base_tables(conn)?;
        set_db_version(conn, 1)?;
    }
    
    if version < 2 {
        create_settings_table(conn)?;
        create_audit_log_table(conn)?;
        create_occupancy_history_table(conn)?;
        set_db_version(conn, 2)?;
    }
    
    Ok(())
}
```

**Tauri Command für Migration:**

```rust
#[tauri::command]
pub async fn run_database_migrations() -> Result<(), String> {
    let conn = get_connection().map_err(|e| e.to_string())?;
    migrations::run_migrations(&conn).map_err(|e| e.to_string())
}
```

import { useEffect } from 'react';

export interface ModalProps {
  open: boolean;
  onClose: () => void;
  title?: string;
  children: React.ReactNode;
  footer?: React.ReactNode;
  size?: 'sm' | 'md' | 'lg' | 'xl';
}

const sizeClasses = {
  sm: 'max-w-sm',
  md: 'max-w-md',
  lg: 'max-w-lg',
  xl: 'max-w-xl',
};

export function Modal({
  open,
  onClose,
  title,
  children,
  footer,
  size = 'md',
}: ModalProps) {
  useEffect(() => {
    if (open) {
      document.body.style.overflow = 'hidden';
    } else {
      document.body.style.overflow = '';
    }
    return () => {
      document.body.style.overflow = '';
    };
  }, [open]);
  
  if (!open) return null;
  
  return (
    <div
      className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/50 backdrop-blur-sm"
      onClick={onClose}
    >
      <div
        className={cn(
          'w-full bg-surface-0 rounded-lg shadow-xl border border-surface-1 animate-in fade-in zoom-in-95',
          sizeClasses[size]
        )}
        onClick={(e) => e.stopPropagation()}
      >
        {/* Header */}
        {title && (
          <div className="flex items-center justify-between p-6 border-b border-surface-1">
            <h2 className="text-xl font-semibold text-text">{title}</h2>
            <button
              onClick={onClose}
              className="text-subtext-0 hover:text-text transition-colors"
            >
              <X className="w-5 h-5" />
            </button>
          </div>
        )}
        
        {/* Content */}
        <div className="p-6">{children}</div>
        
        {/* Footer */}

          <div className="flex items-center justify-end gap-2 p-6 border-t border-surface-1">

// src-ui/components/wizards/WizardLayout.tsx

import { useState } from 'react';
import { ChevronLeft, ChevronRight, Check } from 'lucide-react';
import { Button } from '@/components/ui/Button';
import { cn } from '@/lib/cn';

export interface WizardStep {
  id: string;
  title: string;
  description?: string;
  component: React.ComponentType<WizardStepProps>;
}

export interface WizardStepProps {
  data: Record<string, any>;
  updateData: (data: Record<string, any>) => void;
  goNext: () => void;
  goPrev: () => void;
}

interface WizardLayoutProps {
  steps: WizardStep[];
  onComplete: (data: Record<string, any>) => Promise<void>;
  onCancel: () => void;
  title: string;
}

export function WizardLayout({
  steps,
  onComplete,
  onCancel,
  title,
}: WizardLayoutProps) {
  const [currentStepIndex, setCurrentStepIndex] = useState(0);
  const [data, setData] = useState<Record<string, any>>({});
  const [isSubmitting, setIsSubmitting] = useState(false);
  
  const currentStep = steps[currentStepIndex];
  const isFirstStep = currentStepIndex === 0;
  const isLastStep = currentStepIndex === steps.length - 1;
  
  const goNext = () => {
    if (!isLastStep) {
      setCurrentStepIndex((prev) => prev + 1);
    }
  };
  
  const goPrev = () => {
    if (!isFirstStep) {
      setCurrentStepIndex((prev) => prev - 1);
    }
  };
  
  const updateData = (newData: Record<string, any>) => {
    setData((prev) => ({ ...prev, ...newData }));
  };
  
  const handleComplete = async () => {
    setIsSubmitting(true);
    try {
      await onComplete(data);
    } finally {
      setIsSubmitting(false);
    }
  };
  
  const StepComponent = currentStep.component;
  
  return (
    <div className="max-w-3xl mx-auto">
      {/* Header */}
      <div className="mb-8">
        <h1 className="text-3xl font-bold text-text">{title}</h1>
        <p className="text-subtext-0 mt-2">
          Schritt {currentStepIndex + 1} von {steps.length}
        </p>
      </div>
      
      {/* Step Indicator */}
      <div className="flex items-center justify-between mb-8">
        {steps.map((step, index) => (
          <div key={step.id} className="flex items-center flex-1">
            {/* Step Circle */}
            <div
              className={cn(
                'w-10 h-10 rounded-full flex items-center justify-center font-medium transition-colors',
                index < currentStepIndex
                  ? 'bg-success text-base'
                  : index === currentStepIndex
                  ? 'bg-primary text-base'
                  : 'bg-surface-1 text-subtext-0'
              )}
            >
              {index < currentStepIndex ? (
                <Check className="w-5 h-5" />
              ) : (
                index + 1
              )}
            </div>
            
            {/* Step Label */}
            <div className="ml-3 flex-1">
              <p
                className={cn(
                  'text-sm font-medium',
                  index === currentStepIndex ? 'text-text' : 'text-subtext-0'
                )}
              >
                {step.title}
              </p>
              {step.description && (
                <p className="text-xs text-subtext-0">{step.description}</p>
              )}
            </div>
            
            {/* Connector Line */}
            {index < steps.length - 1 && (
              <div
                className={cn(
                  'h-px flex-1 mx-4 transition-colors',
                  index < currentStepIndex
                    ? 'bg-success'
                    : 'bg-surface-1'
                )}
              />
            )}
          </div>
        ))}
      </div>
      
      {/* Step Content */}
      <div className="bg-surface-0 rounded-lg border border-surface-1 p-6 min-h-[400px]">
        <StepComponent
          data={data}
          updateData={updateData}
          goNext={goNext}
          goPrev={goPrev}
        />
      </div>
      
      {/* Navigation */}
      <div className="flex items-center justify-between mt-6">
        <Button
          variant="ghost"
          onClick={onCancel}
        >
          Abbrechen
        </Button>
        
        <div className="flex gap-2">
          {!isFirstStep && (
            <Button
              variant="outline"
              onClick={goPrev}
            >
              <ChevronLeft className="w-4 h-4" />
              Zurück
            </Button>
          )}
          
          {isLastStep ? (
            <Button
              onClick={handleComplete}
              isLoading={isSubmitting}
            >
              <Check className="w-4 h-4" />
              Abschließen
            </Button>
          ) : (
            <Button onClick={goNext}>
              Weiter
              <ChevronRight className="w-4 h-4" />
            </Button>
          )}
        </div>
      </div>
    </div>
  );
}

use serde::{Deserialize, Serialize};

    pub occupied: i64,
}

pub struct LocationStats {
    pub total: i64,
    pub occupied: i64,
}

#[derive(Debug, Serialize)]
pub struct OccupancyHistoryPoint {
    pub date: String,
    pub percent: f64,
}

#[tauri::command]
pub async fn get_dashboard_data(
    db: State<'_, DbConnection>
) -> Result<DashboardData> {
    let conn = db.0.lock().await;
    
    // Total lockers
    let total_lockers: i64 = conn.query_row(
        "SELECT COUNT(*) FROM lockers",
        [],
        |row| row.get(0)
    )?;
    
    // Occupied lockers (active rentals)
    let occupied_lockers: i64 = conn.query_row(
        "SELECT COUNT(DISTINCT locker_id) FROM rentals 
         WHERE end_date >= date('now') AND deposit_returned = 0",
        [],
        |row| row.get(0)
    )?;
    
    let occupancy_percent = if total_lockers > 0 {
        (occupied_lockers as f64 / total_lockers as f64) * 100.0
    } else {
        0.0
    };
    
    // By size
    let mut by_size = HashMap::new();
    let mut stmt = conn.prepare(
        "SELECT size, COUNT(*) as total,
         (SELECT COUNT(DISTINCT r.locker_id)
          FROM rentals r
          JOIN lockers l2 ON l2.id = r.locker_id
          WHERE l2.size = l.size
          AND r.end_date >= date('now')
          AND r.deposit_returned = 0) as occupied
         FROM lockers l
         GROUP BY size"
    )?;
    
    let rows = stmt.query_map([], |row| {
        Ok((
            row.get::<_, String>(0)?,
            row.get::<_, i64>(1)?,
            row.get::<_, i64>(2)?
        ))
    })?;
    
    for row in rows {
        let (size, total, occupied) = row?;
        by_size.insert(size, SizeStats { total, occupied });
    }
    
    // By location
    let mut by_location = HashMap::new();
    let mut stmt = conn.prepare(
        "SELECT location, COUNT(*) as total,
         (SELECT COUNT(DISTINCT r.locker_id)
          FROM rentals r
          JOIN lockers l2 ON l2.id = r.locker_id
          WHERE l2.location = l.location
          AND r.end_date >= date('now')
          AND r.deposit_returned = 0) as occupied
         FROM lockers l
         GROUP BY location"
    )?;
    
    let rows = stmt.query_map([], |row| {
        Ok((
            row.get::<_, String>(0)?,
            row.get::<_, i64>(1)?,
            row.get::<_, i64>(2)?
        ))
    })?;
    
    for row in rows {
        let (location, total, occupied) = row?;
        by_location.insert(location, LocationStats { total, occupied });
    }
    
    // Overdue returns
    let overdue_returns: i64 = conn.query_row(
        "SELECT COUNT(*) FROM rentals
         WHERE end_date < date('now') AND deposit_returned = 0",
        [],
        |row| row.get(0)
    )?;
    
    // Expiring soon (within 7 days)
    let expiring_soon: i64 = conn.query_row(
        "SELECT COUNT(*) FROM rentals
         WHERE end_date BETWEEN date('now') AND date('now', '+7 days')
         AND deposit_returned = 0",
        [],
        |row| row.get(0)
    )?;
    
    // Damaged lockers
    let damaged_lockers: i64 = conn.query_row(
        "SELECT COUNT(*) FROM lockers WHERE is_damaged = 1",
        [],
        |row| row.get(0)
    )?;
    
    // Pending payments
    let pending_payments_cents: i64 = conn.query_row(
        "SELECT COALESCE(SUM(amount_cents), 0) FROM payments
         WHERE payment_date IS NULL",
        [],
        |row| row.get(0)
    )?;
    
    // Revenue (last 30 days)
    let revenue_30d_cents: i64 = conn.query_row(
        "SELECT COALESCE(SUM(amount_cents), 0) FROM payments
         WHERE payment_date >= date('now', '-30 days')",
        [],
        |row| row.get(0)
    )?;
    
    // Occupancy history (last 30 days)
    let mut occupancy_history = Vec::new();
    let mut stmt = conn.prepare(
        "SELECT snapshot_date, occupancy_percent
         FROM occupancy_history
         WHERE snapshot_date >= date('now', '-30 days')
         ORDER BY snapshot_date ASC"
    )?;
    
    let rows = stmt.query_map([], |row| {
        Ok(OccupancyHistoryPoint {
            date: row.get(0)?,
            percent: row.get(1)?,
        })
    })?;
    
    for row in rows {
        occupancy_history.push(row?);
    }
    
    Ok(DashboardData {
        total_lockers,
        occupied_lockers,
        occupancy_percent,
        by_size,
        by_location,
        overdue_returns,
        expiring_soon,
        damaged_lockers,
        pending_payments_cents,
        revenue_30d_cents,
        occupancy_history,
    })
}

    audit_service::log_action(

// src-ui/hooks/use-keyboard.ts

import { useEffect } from 'react';
import { useNavigate } from 'react-router-dom';

interface KeyboardShortcut {
  key: string;
  ctrl?: boolean;
  shift?: boolean;
  alt?: boolean;
  action: () => void;
  description: string;
}

export function useKeyboardShortcuts(shortcuts: KeyboardShortcut[]) {
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      for (const shortcut of shortcuts) {
        const ctrlMatch = shortcut.ctrl === undefined || shortcut.ctrl === e.ctrlKey;
        const shiftMatch = shortcut.shift === undefined || shortcut.shift === e.shiftKey;
        const altMatch = shortcut.alt === undefined || shortcut.alt === e.altKey;
        const keyMatch = shortcut.key === e.key;
        
        if (ctrlMatch && shiftMatch && altMatch && keyMatch) {
          e.preventDefault();
          shortcut.action();
          break;
        }
      }
    };
    
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [shortcuts]);
}

// src-ui/pages/Screensaver.tsx

import { useEffect, useState } from 'react';
import { Clock } from 'lucide-react';

export function Screensaver({ onExit }: { onExit: () => void }) {
  const [time, setTime] = useState(new Date());
  
  useEffect(() => {
    const interval = setInterval(() => setTime(new Date()), 1000);
    
    const handleActivity = () => {
      onExit();
    };
    
    window.addEventListener('keydown', handleActivity);
    window.addEventListener('mousemove', handleActivity);
    window.addEventListener('click', handleActivity);
    
    return () => {
      clearInterval(interval);
      window.removeEventListener('keydown', handleActivity);
      window.removeEventListener('mousemove', handleActivity);
      window.removeEventListener('click', handleActivity);
    };
  }, [onExit]);
  
  return (
    <div className="fixed inset-0 bg-base flex items-center justify-center">
      <div className="text-center animate-pulse">
        <Clock className="w-24 h-24 text-primary mx-auto mb-4" />
        <div className="text-4xl font-mono text-text">
          {time.toLocaleTimeString('de-DE')}
        </div>
        <p className="text-subtext-0 mt-4">
          Bewegen Sie die Maus oder drücken Sie eine Taste
        </p>
      </div>
    </div>
  );
}

// src-ui/hooks/use-inactivity.ts

import { useEffect, useRef } from 'react';

export function useInactivity(timeout: number, onTimeout: () => void) {
  const timeoutRef = useRef<number>();
  
  const resetTimer = () => {
    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current);
    }
    timeoutRef.current = window.setTimeout(onTimeout, timeout);
  };
  
  useEffect(() => {
    resetTimer();
    
    const handleActivity = () => resetTimer();
    
    window.addEventListener('keydown', handleActivity);
    window.addEventListener('mousemove', handleActivity);
    window.addEventListener('click', handleActivity);
    
    return () => {
      if (timeoutRef.current) {
        clearTimeout(timeoutRef.current);
      }
      window.removeEventListener('keydown', handleActivity);
      window.removeEventListener('mousemove', handleActivity);
      window.removeEventListener('click', handleActivity);
    };
  }, [timeout, onTimeout]);
}

## 17. Code Style & Best Practices

### 17.1 TypeScript/React

- **Naming:**
  - Komponenten: `PascalCase` (`Button.tsx`)
  - Hooks: `camelCase` with `use` prefix (`useLockers.ts`)
  - Utils: `camelCase` (`formatDate.ts`)
  - Types: `PascalCase` (`Locker`, `Rental`)

- **Component Structure:**
  ```tsx
  // Imports
  import { useState } from 'react';
  
  // Types/Interfaces
  interface Props { ... }
  
  // Component
  export function MyComponent({ ... }: Props) {
    // Hooks
    // State
    // Effects
    // Handlers
    // Render
  }
  ```

- **File Organization:**
  - Eine Komponente pro Datei
  - Export als named export
  - Props-Interface vor Komponente

### 17.2 Rust/Tauri

- **Naming:**
  - Functions: `snake_case`
  - Structs: `PascalCase`
  - Commands: `snake_case` (match frontend convention)

- **Error Handling:**
  - Alle Commands geben `Result<T, String>` zurück
  - Custom Error-Type für bessere Fehler-Messages

- **Documentation:**
  - Alle public Commands dokumentieren
  - Docstring mit Beispiel für komplexe Logik

### 17.3 Commit Messages

| TUI-Element | GUI-Äquivalent | Notizen |
|-------------|---------------|---------|
| Window Switcher (^) | Sidebar Navigation | Kategorien mit verschachtelten Seiten |

| Dialog-Wizards | Multi-Step Wizard Modals | Gleiche Logik, visuell ansprechender |
| Fixed-Height Layout | Responsive Pixel Layout | Min 900×600, Optimal 1280×800 |
| ASCII-Animationen | CSS/SVG-Animationen | Screensaver (optional) |
| Terminal Resize | Window Resize | Sidebar kollabiert < 1280px |
| 3x Escape → Dashboard | Logo Click / `Strg+H` | Intuitivere Navigation |
| Tab-Navigation | Sidebar Pages | Gleiche Hierarchie |
