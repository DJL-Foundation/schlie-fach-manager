## 1. Einführung & Zielsetzung

### 1.1 Überblick

Der Schließfach-Manager ist eine Terminal-basierte Anwendung zur Verwaltung von Schließfächern, Verleihvorgängen, Finanzen und Standorten. Version 2.1 fokussiert sich auf:

- **Verbesserung der Usability:** Globale Keybind-Architektur, Window Switcher, Dialog-artige Wizards
- **Fixed-Height Dashboard Layout:** Stabiles Layout bei Terminal-Resize
- **Konfigurierbare Preise:** Pfand, Jahresgebühren, Berechnungszeitraum
- **Erweiterte Export/Import-Formate:** TOML als Default, JSON, CSV, Markdown
- **Audit-Logging:** Vollständige Nachverfolgbarkeit aller Änderungen
- **Historische Analysen:** Belegungstrend, occupancy history
- **3x Escape zum Dashboard:** Quick-Navigation zurück zur Hauptansicht
- **Screensaver:** Automatische Aktivierung nach Inaktivität
- **Robuste Tests:** Unit-, Integration- und UI-Tests mit >85% Coverage
- **Vollständige Dokumentation:** Inline-Dokumentation, README, User Guide

### 1.2 Abwärtskompatibilität

- Datenbank-Migrationen sind kompatibel zu v2.0
- Bestehende Datenbanken werden automatisch migriert
- Export-Formate bleiben rückwärts lesbar

### 1.3 Zielplattformen

- **Betriebssysteme:** Linux, macOS, Windows
- **Terminal:** Jeder moderne Terminal-Emulator mit UTF-8 Support
- **Mindestgröße:** 80x24 Zeichen (optimal: 120x40+)

### 4.4 Status Bar

#### 4.4.1 Basis-Funktionalität

```rust
// ui/widgets/status_bar.rs

pub struct StatusBar {
    message: Option<StatusMessage>,
    escape_count: u8,  // 0-3: Anzahl der aufeinanderfolgenden Escape-Drücke
    last_escape_time: Option<Instant>,
}

pub struct StatusMessage {
    pub text: String,
    pub level: StatusLevel,
    pub timestamp: Instant,
}

pub enum StatusLevel {
    Info,
    Success,
    Warning,
    Error,
}

impl StatusBar {
    pub fn set_message(&mut self, text: String, level: StatusLevel) {
        self.message = Some(StatusMessage {
            text,
            level,
            timestamp: Instant::now(),
        });
    }
    
    pub fn increment_escape_count(&mut self) {
        let now = Instant::now();
        
        // Reset if more than 1 second since last escape
        if let Some(last_time) = self.last_escape_time {
            if now.duration_since(last_time) > Duration::from_secs(1) {
                self.escape_count = 0;
            }
        }
        
        self.escape_count = (self.escape_count + 1).min(3);
        self.last_escape_time = Some(now);
    }
    
    pub fn reset_escape_count(&mut self) {
        self.escape_count = 0;
        self.last_escape_time = None;
    }
    
    pub fn should_return_to_dashboard(&self) -> bool {
        self.escape_count >= 3
    }
    
    pub fn render(&self, area: Rect, buf: &mut Buffer, theme: &Theme) {
        // Split area: left for message, right for escape indicator
        let chunks = Layout::default()
            .direction(Direction::Horizontal)
            .constraints([
                Constraint::Percentage(90),
                Constraint::Percentage(10),
            ])
            .split(area);
        
        // Render message
        if let Some(msg) = &self.message {
            // Auto-clear after 5 seconds
            if msg.timestamp.elapsed() < Duration::from_secs(5) {
                let style = match msg.level {
                    StatusLevel::Info => theme.status_info,
                    StatusLevel::Success => theme.status_success,
                    StatusLevel::Warning => theme.status_warning,
                    StatusLevel::Error => theme.status_error,
                };
                
                let text = Paragraph::new(&msg.text)
                    .style(style)
                    .alignment(Alignment::Left);
                
                text.render(chunks[0], buf);
            }
        }
        
        // Render escape indicator [|||]
        self.render_escape_indicator(chunks[1], buf, theme);
    }
    
    fn render_escape_indicator(&self, area: Rect, buf: &mut Buffer, theme: &Theme) {
        // Format: [|||]
        // Each pipe changes color based on escape_count
        let pipes = ['|', '|', '|'];
        let mut spans = vec![
            Span::raw("["),
        ];
        
        for (i, pipe) in pipes.iter().enumerate() {
            let style = if i < self.escape_count as usize {
                Style::default().fg(theme.accent) // Highlighted
            } else {
                Style::default().fg(theme.text_dim) // Normal/dim
            };
            
            spans.push(Span::styled(pipe.to_string(), style));
        }
        
        spans.push(Span::raw("]"));
        
        let indicator = Paragraph::new(Line::from(spans))
            .alignment(Alignment::Right);
        
        indicator.render(area, buf);
    }
}
```

#### 4.4.2 3x Escape = Dashboard Feature

**Verhalten:**
- Jedes Drücken von `Esc` innerhalb von 1 Sekunde erhöht den Counter
- Visuelles Feedback: Die Pipes `|||` in der Status Bar werden nacheinander hervorgehoben
- Nach dem 3. `Esc`: Automatischer Sprung zum Dashboard
- Counter wird zurückgesetzt wenn:
  - >1 Sekunde seit letztem Escape vergangen
  - Eine andere Taste gedrückt wurde
  - Dashboard erreicht wurde

**Implementierung im Event Loop:**

```rust
// app.rs

impl App {
    pub fn handle_key(&mut self, key: KeyCode) -> Result<AppAction> {
        match key {
            KeyCode::Esc => {
                self.status_bar.increment_escape_count();
                
                if self.status_bar.should_return_to_dashboard() {
                    self.status_bar.reset_escape_count();
                    self.switch_screen(AppScreen::Dashboard);
                    self.status_bar.set_message(
                        "Zurück zum Dashboard".to_string(),
                        StatusLevel::Info,
                    );
                    return Ok(AppAction::Continue);
                }
                
                // Normal escape behavior (close dialog, go back, etc.)
                self.handle_escape_normal()?;
            }
            _ => {
                // Any other key resets escape counter
                self.status_bar.reset_escape_count();
                self.handle_other_key(key)?;
            }
        }
        
        Ok(AppAction::Continue)
    }
}
```

## 5. Screensaver

### 5.1 Konzept

**Zweck:** Reduziert Burn-in Risiko bei langfristiger Inaktivität und zeigt an, dass die App noch läuft.

**Verhalten:**
- Nach **60 Sekunden Inaktivität** (konfigurierbar): 15 Sekunden Countdown in Status Bar
- Nach **15 Sekunden Countdown** ohne Aktivität: Screensaver aktiviert
- **Screensaver-Modus:**
  - Kein Header, keine Keybind Bar, keine Status Bar
  - Vollbild-Ansicht
  - Mittig positionierte ASCII-Animation (endlos Loop)
  - Eine von 5 vorprogrammierten Animationen (zufällig ausgewählt)
- **Deaktivierung:** Bei jeder Tastatureingabe
  - Screensaver endet sofort
  - **Rückkehr direkt zum Dashboard**
  - Vorherige Status Bar Nachricht wird wiederhergestellt

### 5.2 Inaktivitäts-Tracking

```rust
// app.rs

pub struct App {
    // ... existing fields
    last_activity: Instant,
    screensaver_timeout: Duration,  // From settings (default 60s)
    countdown_duration: Duration,   // 15 seconds
    screensaver_active: bool,
    previous_status_message: Option<StatusMessage>,
    previous_screen: Option<AppScreen>,
}

impl App {
    pub fn update_activity(&mut self) {
        self.last_activity = Instant::now();
        
        // If screensaver was active, restore previous state
        if self.screensaver_active {
            self.exit_screensaver();
        }
    }
    
    pub fn check_inactivity(&mut self) -> InactivityState {
        let inactive_duration = self.last_activity.elapsed();
        
        if inactive_duration >= self.screensaver_timeout + self.countdown_duration {
            InactivityState::ScreensaverActive
        } else if inactive_duration >= self.screensaver_timeout {
            let remaining = self.countdown_duration - (inactive_duration - self.screensaver_timeout);
            InactivityState::Countdown(remaining.as_secs())
        } else {
            InactivityState::Active
        }
    }
    
    pub fn activate_screensaver(&mut self) {
        if !self.screensaver_active {
            self.previous_status_message = self.status_bar.message.clone();
            self.previous_screen = Some(self.screen.clone());
            self.screensaver_active = true;
            self.screen = AppScreen::Screensaver;
        }
    }
    
    pub fn exit_screensaver(&mut self) {
        if self.screensaver_active {
            self.screensaver_active = false;
            
            // Always return to Dashboard after screensaver
            self.screen = AppScreen::Dashboard;
            
            // Clear previous screen tracking
            self.previous_screen = None;
            
            // Restore previous status message
            if let Some(prev_msg) = self.previous_status_message.take() {
                self.status_bar.message = Some(prev_msg);
            }
            
            self.update_activity();
        }
    }
}

pub enum InactivityState {
    Active,
    Countdown(u64), // Remaining seconds
    ScreensaverActive,
}
```

### 5.4 ASCII-Animationen

#### 5.4.1 Animation Trait

```rust
// screensaver/animations.rs

pub trait Animation {
    fn name(&self) -> &str;
    fn frames(&self) -> &[&str];
    fn frame_delay_ms(&self) -> u64;
    fn width(&self) -> u16;
    fn height(&self) -> u16;
}

pub struct AnimationFrame {
    pub content: String,
    pub timestamp: Instant,
}

pub struct AnimationPlayer {
    animation: Box<dyn Animation>,
    current_frame: usize,
    last_frame_time: Instant,
}

impl AnimationPlayer {
    pub fn new(animation: Box<dyn Animation>) -> Self {
        Self {
            animation,
            current_frame: 0,
            last_frame_time: Instant::now(),
        }
    }
    
    pub fn update(&mut self) {
        let elapsed = self.last_frame_time.elapsed().as_millis() as u64;
        
        if elapsed >= self.animation.frame_delay_ms() {
            self.current_frame = (self.current_frame + 1) % self.animation.frames().len();
            self.last_frame_time = Instant::now();
        }
    }
    
    pub fn current_frame(&self) -> &str {
        self.animation.frames()[self.current_frame]
    }
}
```

```rust
    pub fn render(&self, f: &mut Frame) {
        let area = f.area();
        
        // Clear background (all black)
        f.render_widget(
            Block::default().style(Style::default().bg(Color::Black)),
            area,
        );
        
        // Calculate center position
        let anim_width = self.player.animation.width();
        let anim_height = self.player.animation.height();
        
        let x = (area.width.saturating_sub(anim_width)) / 2;
        let y = (area.height.saturating_sub(anim_height)) / 2;
        
        // Create centered area
        let center_area = Rect {
            x: area.x + x,
            y: area.y + y,
            width: anim_width,
            height: anim_height,
        };
        
        // Render animation frame
        let frame_content = self.player.current_frame();
        let paragraph = Paragraph::new(frame_content)
            .style(Style::default().fg(Color::Green)) // Matrix-style green
            .alignment(Alignment::Center);
        
        f.render_widget(paragraph, center_area);
    }
}
```

```rust
// main.rs

fn main() -> Result<()> {
    // ... setup
    
    loop {
        // Check inactivity state
        match app.check_inactivity() {
            InactivityState::Active => {
                // Normal operation
            }
            InactivityState::Countdown(seconds) => {
                app.status_bar.show_screensaver_countdown(seconds);
            }
            InactivityState::ScreensaverActive => {
                app.activate_screensaver();
            }
        }
        
        // Render
        terminal.draw(|f| app.render(f))?;
        
        // Handle input
        if event::poll(Duration::from_millis(16))? {
            if let Event::Key(key) = event::read()? {
                app.update_activity(); // Reset inactivity timer
                
                if app.screensaver_active {
                    // Any key exits screensaver
                    app.exit_screensaver();
                } else {
                    // Normal key handling
                    app.handle_key(key.code)?;
                }
            }
        }
        
        // Update screensaver animation if active
        if app.screensaver_active {
            app.screensaver_screen.update();
        }
    }
}
```

```rust
pub fn layout_dashboard(area: Rect) -> Vec<Rect> {

        .constraints([
            Constraint::Length(2),     // Header
            Constraint::Length(9),     // Belegung
            Constraint::Min(6),        // Aktionen (wächst)
            Constraint::Length(7),     // Standorte + Finanzen row
            Constraint::Min(8),        // Trend (wächst)
            Constraint::Length(3),     // Keybind Bar
            Constraint::Length(1),     // Status Bar
        ])
        .split(area);
    
    // Split Standorte + Finanzen horizontal
    let middle_row = Layout::default()
        .direction(Direction::Horizontal)
        .constraints([
            Constraint::Percentage(50),

        .split(main_chunks[3]);
    
    vec![
        main_chunks[0], // Header
        main_chunks[1], // Belegung
        main_chunks[2], // Aktionen
        middle_row[0],  // Standorte
        middle_row[1],  // Finanzen
        main_chunks[4], // Trend
        main_chunks[5], // Keybind Bar
        main_chunks[6], // Status Bar
```
