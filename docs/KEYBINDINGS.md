# Tastenkürzel - Schließfach-Manager v2.1

## Globale Tastenkürzel

| Taste | Beschreibung |
|-------|--------------|
| `^` | Window Switcher öffnen |
| `Esc×3` | Zurück zum Dashboard (dreimal Escape) |
| `q` | Anwendung beenden |

## Window Switcher

| Taste | Beschreibung |
|-------|--------------|
| `Tab` | Nächstes Fenster |
| `Shift+Tab` | Vorheriges Fenster |
| `Enter` | Fenster auswählen |
| `Esc` | Window Switcher schließen |

## Navigation

| Taste | Beschreibung |
|-------|--------------|
| `↑` / `k` | Nach oben |
| `↓` / `j` | Nach unten |
| `Enter` | Auswählen/Bestätigen |
| `Esc` | Zurück/Abbrechen |

## Dashboard

| Taste | Beschreibung |
|-------|--------------|
| `1` | Verleihverwaltung |
| `2` | Finanzen |
| `3` | Verwaltung |
| `r` | Dashboard aktualisieren |

## Verleihverwaltung

| Taste | Beschreibung |
|-------|--------------|
| `n` | Neuer Verleih |
| `e` | Verleih verlängern |
| `r` | Rückgabe |
| `d` | Schaden melden |
| `1` | Tab: Aktive Verleih |
| `2` | Tab: Überfällig |
| `3` | Tab: Bald fällig |

## Finanzen

| Taste | Beschreibung |
|-------|--------------|
| `p` | Neue Zahlung |
| `e` | Export |

## Verwaltung

| Taste | Beschreibung |
|-------|--------------|
| `l` | Standorte |
| `s` | Einstellungen |
| `a` | Audit-Log |
| `i` | Import |
| `x` | Export |

## Wizards

| Taste | Beschreibung |
|-------|--------------|
| `↑` / `k` | Vorherige Option |
| `↓` / `j` | Nächste Option |
| `Enter` | Option auswählen |
| `Esc` | Wizard abbrechen |

## Escape-Indikator

Der Escape-Indikator `[│││]` in der Statusleiste zeigt den Fortschritt:

- `[│││]` - Kein Escape gedrückt
- `[║││]` - Erstes Escape
- `[║║│]` - Zweites Escape
- `[║║║]` - Drittes Escape → Dashboard

Der Zähler wird nach 1 Sekunde ohne Taste automatisch zurückgesetzt.

## Screensaver

- **Aktivierung**: Nach 60 Sekunden Inaktivität
- **Countdown**: 15 Sekunden vor Aktivierung
- **Deaktivierung**: Beliebige Taste drücken
- **Nach Deaktivierung**: Direkt zum Dashboard
