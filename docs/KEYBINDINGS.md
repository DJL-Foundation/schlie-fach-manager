# Tastenkombinationen

## Globale Keybinds (immer verfügbar)

| Taste | Aktion |
|-------|--------|
| `Tab` | Nächster Eintrag/Feld/Tab |
| `Shift+Tab` | Vorheriger Eintrag/Feld/Tab |
| `^` (Caret) | Window Switcher aktivieren |
| `Shift+Q` | Programm beenden |
| `Esc` | Abbrechen / Zurück / Dialog schließen |
| `Esc` x3 | **Direkt zum Dashboard** (innerhalb 1 Sekunde) |
| `Enter` | Bestätigen / Auswählen |

## Escape-Indikator

Rechts unten in der Status Bar: `[|||]`

- Erste Pipe leuchtet nach 1x Esc
- Zweite Pipe leuchtet nach 2x Esc
- Dritte Pipe leuchtet nach 3x Esc → Sprung zum Dashboard
- Reset nach 1 Sekunde oder bei anderer Taste

## Dashboard

| Taste | Aktion |
|-------|--------|
| `1` | Neuen Verleih suchen (→ Verleih-Management: Search) |
| `2` | Verleihliste (→ Verleih-Management: List) |
| `3` | Vertrag verlängern (→ Verleih-Management: Extend) |
| `4` | Rückgabe (→ Verleih-Management: Return) |
| `5` | Defekt melden (→ Verleih-Management: Damage) |

## Finanzen

| Taste | Aktion |
|-------|--------|
| `E` | Export ausführen |
| `I` | Import ausführen |

## Screensaver

- Aktivierung: Nach 60s Inaktivität + 15s Countdown
- Deaktivierung: Beliebige Taste → **Direkt zum Dashboard**
- Animationen: 5 verschiedene ASCII-Animationen (zufällig)
