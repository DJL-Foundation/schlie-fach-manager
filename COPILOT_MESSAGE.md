# Nachricht an Copilot

Lies dir die **v2.1 spec.md** vollständig und gründlich durch.

**WICHTIG:** Achte darauf, dass du **wirklich ALLES** aus der Spezifikation implementierst:

✅ **Checkliste während der Implementierung:**

1. **Lies die gesamte Spec** bevor du beginnst
2. **Implementiere iterativ** - eine Aufgabe nach der anderen
3. **Teste nach jedem Schritt** - alle Tests müssen grün sein
4. **Keine Placeholder** - lösche alle TODO/PLACEHOLDER Kommentare
5. **Dokumentiere alles** - jede Funktion, jedes Modul
6. **Verifiziere mehrfach** - prüfe ob du wirklich alle Spec-Punkte umgesetzt hast
7. **Mapping zur Spec** - dokumentiere in jedem Commit/PR welche Spec-Punkte erfüllt wurden

⚠️ **Vermeide diese Fehler:**

- ❌ Funktionen nur teilweise implementieren
- ❌ Placeholder-Kommentare hinterlassen
- ❌ Tests auslassen oder überspringen
- ❌ Dokumentation vergessen
- ❌ Von der Spec abweichen ohne Rücksprache
- ❌ Große Änderungen ohne Tests committen

✨ **Arbeitsweise:**

- Arbeite **Schritt für Schritt** durch die Prioritäten (Hoch → Mittel → Niedrig)
- Nach **jeder abgeschlossenen Aufgabe**: Tests, Docs, Review
- Erstelle **fokussierte PRs** mit klarem Mapping zu Spec-Abschnitten
- **Frage nach** wenn etwas unklar ist, statt zu raten

📋 **Vor jedem PR/Commit:**

- [ ] `cargo test` - alle Tests grün?
- [ ] `cargo clippy` - keine Warnings?
- [ ] `cargo fmt` - Code formatiert?
- [ ] Dokumentation aktualisiert?
- [ ] CHANGELOG.md erweitert?
- [ ] Keine TODOs/PLACEHOLDERs mehr?
- [ ] Spec-Punkte in PR-Beschreibung gemappt?

🎯 **Ziel:** Eine vollständige, robuste, gut dokumentierte und getestete Implementierung nach v2.1 Spec.

**Viel Erfolg! 🚀**
